# Archive - Script Eksperimen & Prototype

Folder ini berisi script eksperimen/prototype yang tidak digunakan sebagai pipeline runtime final, tetapi disimpan untuk dokumentasi perkembangan project.

## Daftar Script Eksperimen
1. **train_models.py**: Script training awal berbasis data model baseline.
2. **train_models_from_dataset_features.py**: Script training model baseline langsung dari dataset.
3. **train_final_f01_f30_models.py**: Script training model simbolik F01-F30 final.
4. **train_resilient_f01_f30_models.py**: Script training resilient F01-F30 model awal.
5. **validate_final_models.py**: Validasi model simbolik F01-F30 baseline.
6. **validate_resilient_model.py**: Validasi model resilient awal.
7. **inspect_dataset.py**: Script diagnostik untuk memahami distribusi dataset.
